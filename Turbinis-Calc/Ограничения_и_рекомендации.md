## 4. Чувствительность: что менять и на что это влияет

| Параметр | Как влияет | Куда менять для цели | Ограничение |
|---|---|---|---|
| D_с ступени (D_ст) | l_с ∝ 1/D_с; α₂ растёт с u (с D) | **уменьшать D — длиннее лопатка, но ниже α₂**; увеличивать D — короче лопатка, выше α₂ | D_ст[-1] = 1; D растут по ходу газа |
| l_т/D_т | больше lD → меньше D_т → длиннее лопатки, ниже u и α₂ | увеличивать для длины, уменьшать для α₂ | ≤ 1/3 (стр. 58) |
| α₁ | l_с ∝ 1/sin α₁; меньше α₁ → длиннее лопатка; α₂ немного падает | уменьшать для длины (но ≥ 11°) | 11…14° малые турбины |
| ρ (по l/D) | выше ρ → меньше c₁ → длиннее лопатка; α₂ падает | повышать для длины | только по таблице стр. 58; у корня ≥ 0,05 |
| π ступени (веса) | выше нагрузка → короче лопатка; π ≤ 2,4 | снижать для длины | 1,8…2,4 |
| κ = c₂a/c₁a | перераспределяет длину между СА и РЛ; влияет на α₂ | подбирать под рост длин и α₂ | c₂a > c₁a; κ > 1 у 1-й |
| σ_л | u ∝ √σ_л; длина почти не меняется | повышать для α₂ (осторожно) | ≤ 290…300 МПа (до 400 по книге) |
| c_т за турбиной | выше c_т → меньше A_т → больше n и u → короче? (в текущей модели A_т подбирается, длина слабо меняется) | — | 120…200 м/с (стр. 56) |
| z | больше z → меньше H₀ ступени → длиннее лопатки, но π падает | z = 4 невозможен при π ≥ 1,8 | z = 3 |

**Вывод по длине:** чтобы удлинить l_с1, нужно **уменьшать диаметр** (D_ст), **уменьшать α₁** и/или
**снижать нагрузку 1-й ступени**; увеличение D (как иногда кажется) лопатку **укорачивает** (l = A/(πD)).
Это подтверждено перебором: при увеличении D₀ с 0,75 до 0,95 l_с1 падает с 15,3 до 11,7 мм,
а α₂ 1-й ступени растёт с 30,7 до 75,3°.

## 5. Совместимость: жёсткий α₂ по книге и l_с1 ≥ 20 мм

Перебор 418 вариантов (скрипт `podbor_parametrov.py`, запускался в контейнере; после отката удалён)
по D_ст, l_т/D_т, α₁, π_веса, κ_ст, σ_л с проверкой всех ограничений раздела 3 и l_с1 ≥ 20 мм:

| Что искали | Результат |
|---|---|
| Полное совмещение (книга + l_с1 ≥ 20 мм) | **0 вариантов** |
| Максимум l_с1 при книжном α₂ (70…90/80…90), π, α₁ ≥ 11° | **≈ 9,0 мм** |
| Вариант с l_с1 ≥ 20 мм | 20,1 мм, но α₂ = **15/87/90°**, α₁ = **7,5/12,3/17,8°**, u = 404 м/с, длины убывают |

Лучший книжный вариант (α₂ 89/89/88°, π 2,10/2,09/2,35, α₁ 11,6/13,6/20,4°):

```
D_ст = [0.957, 0.973, 1.0]
l_т/D_т = 0.252
α1_ст = [11.6, 13.6, 20.4]°
π_веса = [0.867, 0.861, 1.0]
κ_ст = [1.15, 1.0, 1.0]
σ_л = 292 МПа
→ l_с1 = 9,0 мм (требование 20 мм не выполнено)
```

Вариант с l_с1 = 20,1 мм:

```
D_ст = [0.666, 0.958, 1.0]
l_т/D_т = 0.290
α1_ст = [7.5, 12.3, 17.8]°
π_веса = [0.874, 1.042, 1.0]
κ_ст = [1.12, 1.10, 0.94]
σ_л = 370 МПа
→ α2 = 15/87/90° (1-я ступень вне книги), u = 404 м/с, длины убывают
```

**Причина:** α₂ ≥ 70° — почти осевой выход; для него нужна высокая окружная скорость,
то есть большой средний диаметр (D₀ ≈ 0,95). А длина лопатки l_с ∝ 1/D_с. Поэтому при книжном α₂
лопатка 1-й ступени физически получается ~9 мм, а не 20 мм. Жёсткий α₂ несовместим даже с прежним
проектным l_с1 ≥ 14 мм.

**Варианты решения (выбрать один):**
- **A. Книжный α₂** — принять l_с1 ≈ 9 мм, снизить требование 20/14 мм; блокнот считает без ошибок.
- **B. l_с1 ≥ 20 мм** — ослабить α₂ 1-й ступени (≈ 15°) и α₁ (≈ 7,5°), допустить u > 400 и неплавный рост длин.
- **C. Компромисс** — l_с1 ≈ 14…18 мм при α₂ 1-й ступени 20…40° (как в текущем варианте 17,8 мм при 21,7°).
- **D. Менять цикл/компоновку** — другое π\*к, T\*г, N или z; при текущих π\*к = 11, T\*г = 1250 К, N = 110 кВт и z = 3 полного совмещения нет.

## 6. Постоянный диаметр втулки (обсуждалось, в блокнот не внесено)

Если принять D_в = const, то для каждой ступени:

```
D_с = D_в + l_с,   D_л = D_в + l_л
l_с = G_c·v₁ / (π·D_с·sin α₁·c₁)
l_л = G_л·v₂ / (π·D_л·c₂a)
```

Решается итерацией: задали D_с, D_л → посчитали ступень → уточнили D_с = D_в + l_с, D_л = D_в + l_л.
Диаметр втулки при этом заменяет D_ст как входной параметр; D_ст становится выходом (D_с/D_т).

Предварительные прогоны (постоянная втулка, книга: l_т/D_т ≤ 1/3):

| D_в, мм | l_с1, мм | α₂, ° | Комментарий |
|---|---|---|---|
| ≈ 77 | 11,8 | 77,8 / 98 / 105,6 | α₂ 2-й и 3-й > 90° |
| ≈ 66 | 13,2 | 46 / 57 / 80 | α₂ 1-й и 2-й < 70° |
| ≈ 58 | 15,0 | 31 / 35 / 58 | α₂ всех ступеней ниже книги |
| ≈ 52 | 17,2 | 23 / 25 / 44 | l_т/D_т уже > 1/3 (0,383) |

**Вывод:** постоянная втулка не снимает противоречие «α₂ по книге ↔ длинная лопатка». Она лишь
перепараметризует его. По предварительным прогонам (полного перебора с постоянной втулкой не делалось):
при D_в ≈ 70…80 мм α₂ 1-й ступени попадает в книжный диапазон, но 2-я и 3-я ступени выходят за 90°,
а l_с1 ≈ 12…13 мм; при D_в ≈ 45…50 мм l_с1 растёт до ~17…20 мм, но α₂ 1-й ступени падает до ~15…20°,
а l_т/D_т выходит за 1/3. Для окончательного ответа нужен отдельный перебор уже с моделью постоянной втулки.

Если постоянную втулку всё же принять, менять нужно `D_в` (или `l_т/D_т` как начальную оценку),
а не `D_ст`; в блокноте потребуется заменить `D_с = D_л = D_ст[i]·D_т` на итерацию по D_в
(затрагиваются разделы 5, 6, 7, 12, 14 и `make_mathcad.py`).
