## 9. Отступления в текущем варианте (z = 3, l_с1 = 14,1 мм)

1. α₂ за 1-й ступенью 29° при книжном допуске 70…90°.
2. u_т = 385 м/с (σ_л = 290 МПа) вместо 350 м/с (239 МПа) из цикла.
3. Скорость за турбиной 178 м/с вместо 108 м/с из цикла.
4. Запас по ограничениям минимален: l_с1 = 14,1 мм (≥ 14), π 3-й ступени 2,40 (≤ 2,4), РЛ 1-й ступени = СЛ 2-й ступени (14,4 мм).
5. Короткие лопатки (< 40…50 мм): φ и ψ проверены по потерям в решётках (раздел 10 ниже) — принятые 0,97 / 0,96 с запасом.
6. Угол раскрытия на участках до 16,4° (желательно 12°).
7. У корня СА 2-й и 3-й ступеней λ_c1 = 1,07 / 1,09 > 1,05 (стр. 78) — слегка сверхзвуковое истечение с поворотом потока в косом срезе; на среднем радиусе λ_c1 ≤ 0,91.
8. Профилирование 1-й ступени (α₁ = const): у корня при L_u = const решения нет (w₂ < w₂u), там принято c₂a = const.
