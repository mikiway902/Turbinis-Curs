# ТЗ: диагностика и замыкание α₁-ступени (часть 6Б-4.5)

Дата: 2026-11-09. Основание: `REPORT_STAGE6B5.md` (шаги 4–5), `radial_exit.py`.

Не затрагивать оптимизатор и Γ-ступени. Работать только с выходом 2-й ступени
(закон α1 = const).

## 0. Что установлено

- Выход РК для Γ-ступеней замыкается: невязка равновесия 0.01–0.02 %,
  расход −0.08…−0.28 %.
- Для α₁-ступени: невязка равновесия **13.4 %** от max|dp/dr| (ранее
  приводилось 9599 % — это артефакт поточечной нормировки: `dp/dr` меняет
  знак по высоте).
- Разбор по членам на втулке: `dp/dr` = 673 кПа/м, `ρc_u²/r` = 75 кПа/м,
  `−ρT·ds/dr` = 508 кПа/м, остаток 90 кПа/м. Доминирует энтропийный член.
- Энергия (`L_u`) и расход на выходе согласованы; рассогласованы только
  `T2(r)`, `s2(r)` и равновесие.

## 1. Диагностика (А)

Не менять модель. Для каждого сечения r вывести:

| величина | формула |
|---|---|
| `T2(r)` | из энергии в относительном движении |
| `p2(r)` | уравнение состояния при известных `T2`, `s2` |
| `(dp2/dr)_факт` | численная производная `p2(r)` |
| `(dp2/dr)_равн` | `ρ2(c2u²/r − T2·ds2/dr)` |
| члены | отдельно `ρ2c2u²/r` и `−ρ2T2·ds2/dr` |
| невязка | `Δ = (dp2/dr)_факт − (dp2/dr)_равн` |

Дополнительно:

1. Найти точки, где `dp2/dr` меняет знак, и объяснить причину.
2. Повторить с `s2 = const` (без потерь РК) — понять, сколько невязки даёт
   энтропийный член, а сколько — распределение `c2u(r)`.
3. Повторить с `T2 = const` — проверить вклад температуры.
4. Сравнить `c2u(r)` для α₁-закона (из `L_u = const`) с «гладкими» законами
   (Γ, `c2u·r = const`) по величине и знаку градиента.

Критерий: назвать источник невязки — закон `c2u(r)`, энтропийное замыкание,
граничное условие или `T2(r)`.

## 2. Совместное решение (Б)

Решить связанную систему на выходе:

```
энергия:      L_u(r) = c1u·u1 + c2u·u2   (на каждой линии тока)
состояние:    p2 = ρ2 R T2
энтропия:     s2(r) = s1(r) + h_л(r)/T2(r)
равновесие:   dp2/dr = ρ2(c2u²/r − T2·ds2/dr)
расход:       ∫ρ2·c2a·2πr dr = G_л
BC:           p2(r_ср) = p2 из среднесечного расчёта
```

Неизвестные: `p2(r)`, `T2(r)`, `c2u(r)`, `ρ2(r)`; `c2a` — из неразрывности
или закона.

Метод: стрельба/Ньютон по двум параметрам (например, `p2` на втулке и
наклон `c2u`), контроль — расход и `p2(r_ср)`. Проверить существование
решения **при исходном законе α1 = const**.

Если решения нет — зафиксировать несовместимость именно при этих условиях
(закон α1, потери РК, BC), а не объявлять закон универсально неверным.

## 3. Альтернативное профилирование (В)

Только если Б не даёт решения: подобрать закон `c2u(r)` (или `α2(r)`),
замыкающий ступень при тех же энергии, потерях и BC. Проверить:

- `α2(r)` в допустимом диапазоне (70…90°);
- `w2 > c2a`;
- `α1_корня ≥ 11°` на входе;
- расход и работу.

## 4. Критерии приёмки

| проверка | критерий |
|---|---|
| невязка равновесия | ≤ 1 % от max|dp/dr| по всему сечению |
| расход | ≤ 0.5 % |
| энергия | `L_u(r)` постоянна до 1e-6 |
| состояние | `p2 = ρRT2` по радиусу, размерности |
| BC | решение не зависит от способа якоря в пределах 1 % |
| α2(r) | в книжном диапазоне |

## 5. Чего не делать

- Не подбирать `T2(r)` или `p2(r)` под проход `ρ_корня ≥ 0.05`.
- Не заменять энергетическое уравнение уравнением равновесия.
- Не менять Γ-ступени и оптимизатор.
- Не запускать 6Б-5.
