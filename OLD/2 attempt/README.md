# Рабочий двухступенчатый расчёт турбины

Рабочая папка проекта — **1-Turbinis-Curs-Last**. Остальные прежние материалы находятся в **../OLD**; это архив, не исходные данные текущей машины. Служебная `.git` остаётся в корне репозитория.

## Расчётные конфигурации

| Ноутбук | Ресурс, ч | Частота, об/мин |
|---|---:|---:|
| `TVD_1CBK_2st_300h.ipynb` | 300 | 38800 |
| `TVD_1CBK_2st_2000h.ipynb` | 2000 | 33200 |
| `TVD_1CBK_2st_10000h.ipynb` | 10000 | 30700 |

Во всех трёх: **две ступени, 110 кВт после редуктора, 1250 K**. ЦБК считается только в цикле. Газодинамические формулы находятся в соответствующем ресурсном ноутбуке и не заменяются архивным трёхступенчатым расчётом.

## Где посмотреть профили

Откройте **`Vinogradov_Integration.ipynb`** и выберите ресурс 300, 2000 или 10000 ч.
Готовые рисунки: **`exports/profiles/<ресурс>h/profiles.png`**.

Для перестроения выполните раздел **33. Профили лопаток по Виноградову** основного ресурсного ноутбука.
Он рисует СА1, РК1, СА2, РК2 только на корневом, среднем и периферийном радиусах.
Новый оптимизатор, пересчёт потерь и прочности не запускаются; внутри каждого венца одинаковый масштаб трёх рисунков.

## Лопатки по Виноградову

- `vinogradov/` — аналитические профили, решётки, горло, геометрические характеристики, прочность и CAD.
- `Vinogradov_Integration.ipynb` — простой просмотр чертежей выбранного ресурса.
- `run_vinogradov.py` — отдельный экспериментальный полный расчёт; для просмотра профилей не нужен.
- `tests/blading/` — контрольные примеры и расчётные проверки.
- `docs/vinogradov/README.md` — методика, запуск и границы применимости.
- `docs/vinogradov/SOURCE_MAP.md` — словарь и соответствие формулам/страницам.
- `docs/vinogradov/JOURNAL.md` — выполненные проверки, ошибки источника и открытые вопросы.
- `exports/vinogradov/` — контрольные примеры и ресурсные результаты.

Установка зависимостей из этой папки: `python -m pip install -e '.[test,cad,notebook]'`.

Прежняя ошибочная привязка новых лопаток к трёхступенчатому `Turbinis-Calc` и её численные отчёты архивированы в `../OLD`. Их числа не характеризуют эти двухступенчатые конфигурации. Новые связи имеют статус EXPERIMENTAL; программный тест и геометрическая валидность STEP не подтверждают назначенный ресурс двигателя.

Недостающие данные вибрационной прочности и точные частотные масштабы трёх ресурсов: [docs/vinogradov/HCF_INPUTS.md](docs/vinogradov/HCF_INPUTS.md). Неизвестный запас HCF не становится выполненной проверкой.
