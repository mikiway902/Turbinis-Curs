# Автоматизированное профилирование по Виноградову

Дополнение к **двухступенчатому курсовому проекту** в `Turbinis-Curs/1-Turbinis-Curs-Last` (далее COURSE), не новая газодинамика и не трёхступенчатый `Turbinis-Calc`. Все новые методы EXPERIMENTAL. Основной источник: Л.В. Виноградов, 2010, 88с.; номера печатных страниц совпадают с PDF. Все пути и команды ниже — относительно COURSE.

## Вход и запуск

```bash
python -m pip install -e '.[test,cad,notebook]'
python run_vinogradov.py --source-only
python run_vinogradov.py --resource 300 --iterations 3 --geometry-iterations 4
python run_vinogradov.py --resource 2000 --iterations 3 --geometry-iterations 4
python run_vinogradov.py --resource 10000 --iterations 3 --geometry-iterations 4
```

Интерфейс Jupyter: `Vinogradov_Integration.ipynb`, запуск с рабочим каталогом COURSE. `RESOURCE_HOURS` выбирает 300/2000/10000ч. Он читает только `exports/vinogradov/<ресурс>h/report.json`, проверяет ресурс, источник, две ступени и четыре венца. Если отчёта нет, вызывает `run_design(resource_hours=...)`; `RECALCULATE=True` требует нового расчёта. Сохранённый отчёт не выдаётся за пересчёт.

|---|---|---|
| 300 | `TVD_1CBK_2st_300h.ipynb` | 38800 |

В каждом исходном ноутбуке в конце добавлен отдельный раздел **«Виноградов: действительный P0 этого ресурсного расчёта»**. Он вызывает `vinogradov.integration.design_from_namespace(globals(), options)` после исходного принятого расчёта `P0`, задаёт `VINOGRADOV_SOURCE_NOTEBOOK`, ресурсный каталог и требования из `STRENGTH_REQUIREMENTS`. Исходные газовые формулы и прежние кубические профили не переписываются. Новый аналитический метод показан **рядом**, а не переименовывает старые профили.

В добавленном разделе по умолчанию `VINOGRADOV_OPTIMIZE_GEOMETRY=False`: сравнение нового метода на принятой компоновке и Z без незапрошенного переподбора. `True` включает отдельный поиск новой геометрии/Z. CLI `run_design` по умолчанию выполняет оптимизацию и пос­тупенчатую обратную связь; обе возможности сохранены.

Программный вход из COURSE:

```python
from run_vinogradov import run_design
report = run_design(resource_hours=2000)
```

`vinogradov.course_adapter.load_course_notebook(path)` выполняет подлинные определения, настройки выбранного ресурса и исходный принятый `coupled_turbine_design`, а не читает сохранённые картинки/числа. Добавленный раздел Виноградова не загружается рекурсивно; несвязанные рисунки и чувствительности не являются необходимым источником `P0`. Радиальные поля/канал берутся из действительных функций исходного проекта и его переменных свойств газа; постоянная cp и трёхступенчатый оптимизатор не подставляются.

## Что считается

- Истинные параметрические параболы как огибающие касательных; окружности и G1-сопряжения. Нет косметического сглаживания, изменяющего углы/горло.
- Расчётная схема, одиночная параболическая спинка, двухрадиусное корытце, заданная толщина/положение, двухпараболическая спинка, активный дозвуковой профиль. Заданная толщина и две параболы используют **один** источник построения: табл.4 задаёт схему, табл.5 замыкает её двумя параболами, это не две скопированные реализации.
- Точный чёткий смысл входного металла `flow+i`, выходного `flow−delta`. Нельзя автоматически подменять эффективным углом направление фактического потока.
- Формула Дышлевского проверена по изображению с.11. Общий Z на весь венец, локальный t=2πr/Z, нечётные СА/чётные РК и увеличение Z — сохранённые решения пользователя, не законы Виноградова.
- Нормальные вписанные окружности профиля и канала, ширина/горло, центр линии канала, конфузорность, расширяющиеся интервалы, реальные контакты с конечной выходной кромкой.
- Табл.3.3: реальные интегралы площади и моментов, главные оси, распределённые моменты сопротивления и длины обводов. Условный прямоугольник не заменяет профиль.
- Пять секций для предварительного центробежного растяжения, уточнение квадратичной площадью по трём, интегрирование газовых сил и косой изгиб. Неизвестный допуск LM даёт отказ, а не бесконечный запас.
- Температурная зависимость E/предела текучести и LM IN738C с отдельными источниками. Нормальная длительная прочность не подменяет общую.
- Предварительные балочные частоты с геометрической жёсткостью, диаграмма возбуждения; API гармонического отклика требует **явных** сил, демпфирования и усталостного допуска. IN738LC из табл.XII не подставляется вместо IN738C.
- Если предшествующий СА не построен и его Z неизвестно, частота лопаточного возбуждения не подставляется из другого РК; Campbell получает NOT_CHECKED.
- Совмещение СА по входным кромкам, РК по центрам масс; физическое окружное отражение СА; адаптивные промежуточные секции с измеренной ошибкой, а не декоративный loft из трёх картинок.
- Оптимизация геометрии, целого Z, закона площади и отдельных осевых зазоров. Сохранение всех оценённых/отвергнутых попыток; обратная связь фактических кромочных потерь в существующие φ/ψ.
- Независимая чувствительность ПК/ЗК и натекания: восемь действительных перестроений среднего профиля, фактическое горло, загромождение кромкой, кривизна и нарушения. Это геометрическая оценка, а не выдуманная аэродинамическая поляра. Результаты находятся в `row.edge_radius_sensitivity`.

## Полный расчёт и границы применимости

Активная схема: **две ступени, четыре венца SA1/RK1/SA2/RK2**, 110кВт **после редуктора**, 1250К, фиксированная частота выбранного ресурсного ноутбука. ЦБК — только в цикле. Материал, плотность, кривая LM, ресурс, обязательный запас, расход, углы, сужение и проектные ограничения берутся из фактического namespace. Исходный обязательный LM-запас1.2 не ослабляется до1.0 ради прохождения нового метода.

Прежняя интеграция в трёхступенчатый `Turbinis-Calc` была **ошибкой выбора целевого проекта**. Её расчёты и файлы архивированы в ROOT/OLD; журнал ниже сохраняет числа как историческое свидетельство, не как результаты этой машины. Ни высота СА около9мм, ни прежние M>1, ни ограничения той оптимизации не переносятся в ресурсный расчёт.

Профилирование не исправляет незамкнутое радиальное поле. Независимо проверяются импульс по радиусу, общая форма равновесия, интеграл расхода, баланс энергии, Эйлер и треугольники. Для статора/ротора передаются отдельные статические и полные состояния. `c2u` исходного курса имеет противоположный физическому `c_theta` знак; адаптер исправляет **представление**, не уравнение Эйлера.

Для M≥1 дозвуковая рекомендация явно отклоняется. Такой отказ — конкретная граница применимости, не доказательство отсутствия трансзвукового решения. Для частично реактивной по высоте лопатки бинарное переключение геометрического семейства не допускается: используется общее двухпараболическое семейство с локальными углами, а предпочтённый по каждому сечению метод сохраняется в протоколе.

Толщина конца 2–3мм при 4–5% требует хорды 40–75мм. Для малоразмерной турбины это может быть несовместимо с доступной осевой шириной/шагом/числом лопаток. Код выводит фактическую толщину, необходимую хорду и источник рекомендации; не вводит необоснованный жёсткий минимум. Аналогично треугольник рассеяния масс 2–3мм сопоставляется с высотой лопатки и не становится универсальным допуском.

Ориентиры прежнего кубического профилирования (постоянная относительная толщина, свой диапазон шага, радиуса носка и заострения) сохраняются как **сравнительные предупреждения**, не переносятся скрыто в физические ограничения нового метода. Геометрическая площадь меняет **синус**, а не угол в градусах: `asin(a·hгорла/(t·hвыхода))`; это площадной эквивалент при предположении одинакового массового потока на единицу площади, не фактический угол выхода газа. Пересечения, неположительное горло, незамкнутая геометрия, расход/запирание, источниковые проектные ограничения и прочность продолжают проверяться независимо.

Геометрический поиск разделяет мягкие эмпирические ориентиры и явные ограничения курса. Этап SLSQP работает в нормированных переменных с исходными физическими границами; проверяет осевой габарит, конечную толщину кромки, требуемое критическое проходное сечение и заданное радиальное изменение хорды/площади. Допустимость имеет приоритет перед целевой функцией при выборе целого Z. Расстояние между точками сетки используется только для предварительной оценки: для ограничения расхода ищется непрерывный минимум между аналитическими стенками, а окончательный отчёт независимо проверяет касательные вписанные окружности и действительную переменную теплоёмкость газа. Достижение лимита итераций не считается сходимостью или доказательством несовместимости.

Длительная прочность: INCO497, IN738C, вакуумное литьё, термообработка 2050°F/2ч/air +1550°F/24ч/air. Табл.IX **C**, не LC; C_LM=20 — явное приближение. Интерполяция logσ(P), **без экстраполяции** P и без аттестованного статистического допуска. Recovery=1 по двум плоскостям РК — оценка верхней температуры, не решение теплопроводности. Не вычисляется фиктивная деформация ползучести из одного времени разрушения. Замок, концентраторы, диск и тепловые градиенты не становятся проверенными от наличия нормального напряжения пера.

## Выход

Общие контрольные примеры пособия: `exports/vinogradov/controls/`, включая `control_errors.csv/json` с абсолютными/относительными ошибками, `source_controls.png` и `elementary_stage_source.png`. Это проверки методики, не доказательство допустимости ресурсной турбины.

Для каждого ресурса отдельно: `exports/vinogradov/300h/`, `2000h/`, `10000h/`:

- `report.json` — фиксированный вход UI: фактический источник, ресурс, две ступени, четыре венца, параметры, нарушения, фигуры и коэффициенты скорости;
- `REPORT.md`, `coupled_report.json` — итог и протокол согласования;
- `SA1_parameters.csv` и аналогичные таблицы остальных венцов, фактически оценённые варианты и причины отказов;
- чертежи профилей/каналов, толщин/кривизны, свойств, треугольников, меридионального канала и3D;
- `*.dxf` — аналитические 2D окружности/параболы в мм;
- `turbine_rows.step` — проверенные OpenCascade solids только при успешном построении.

На профильных чертежах — строго **корень/середина/периферия**. Прочность использует пять сечений трапециями и три с квадратичной площадью; адаптивная CAD-сетка не расширяет число демонстрируемых профильных сечений. Одинаковое Z по высоте венца, нечётные СА/чётные РК, строго возрастающие уникальные Z четырёх венцов, корневая хорда РК больше периферийной и окружное отражение СА сохраняются. Несовместимость геометрии с исходным каналом количественно показывается, а не устраняется косметическим сглаживанием.

STEP учитывает цилиндрические, а не плоские корневые/периферийные секции: сшивается линейчатая боковая оболочка с цилиндрическими крышками. Дискретизация контура/высоты — явная численная точность. Невалидный или несогласованный loft не экспортируется как якобы пригодная 3D-лопатка. Повторный импорт STEP тестирует наличие тел и объём.

Венцы STEP собираются пространственными **экземплярами** одной топологии пера на венец; геометрия dense-loft не копируется целиком для каждого углового положения. Крышки строятся только на корне/периферии. Численная сходимость сетки остаётся отдельной проверкой.

Невозможность получить допустимую конфигурацию в конечном поиске **не является доказательством глобальной математической невозможности**. Итоговый отчёт различает физическое нарушение, неприменимость дозвуковой методики, отсутствие исходных данных и ограниченный исследованный диапазон. Нельзя объявлять комплекс завершённым и турбину допустимой только по зелёным программным тестам.

## Явный запас длительной прочности

В ресурсном курсе `required_lm_margin` передаётся из **`STRENGTH_REQUIREMENTS['required_margin']`** (исходное значение1.2), а часы — из `life_hours` того же источника. Общий библиотечный порог1.0 не переопределяет явное требование курса. Запас и обязательный порог сохраняются для каждого сечения. **Максимальное действительное нормальное напряжение300МПа из ТЗ проверяется отдельно** от LM/температурного допуска материала. Книжный предварительный ориентир200МПа для кольцевой оценки Kn сохранён в исходном расчёте; это другая величина и не подмена ограничения300МПа.

## Модальные напряжения и недостающие данные HCF

`blade_strength.modal_section_stress` восстанавливает напряжения реального контура из вторых производных эрмитовых форм: κ=d²v/dr², σ=E(T)(x−xc)κ. Это та же одна осевая поляризация, что у `beam_modes`; две заделанные степени свободы возвращаются до дифференцирования. Матрица напряжений по единичным обобщённым координатам передаётся в `vibration_response`, где необходимы действительные гармонические силы, демпфирование и усталостной допуск. Проверка на независимой аналитической первой форме консольной балки с ζ=1.8751040687 и нормировкой по непрерывной массе воспроизводит корневое напряжение с допуском0.2%.

Не найденная в проверенных открытых источниках температурная S–N-кривая **IN738C** не заменяется IN738LC. [Изготовитель SeAH](https://www.seahsuperalloys.com/superalloys/in-738-lc) прямо указывает пониженный углерод и различие вариантов; [первичная работа TMS1984](https://www.tms.org/Superalloys/10.7449/1984/Superalloys_1984_63_71.pdf), найденная поиском усталости, посвящена **LC** и низкоцикловому, а не требуемому высокоцикловому режиму. Отсутствие найденных данных не означает доказанное отсутствие публикаций; для данного расчёта допуск остаётся неизвестным. Амплитуда возбуждения конкретной турбины также не восстанавливается из одного Z.
