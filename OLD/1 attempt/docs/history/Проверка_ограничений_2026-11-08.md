# Проверка ограничений проекта по книге Михальцева

**Дата:** 2026-11-08  
**Проверено по PDF:** с. 34, 37, 38, 53, 56–58, 62–63, 87, 90  
**Проверено по коду:** `Turbinis-Calc/Main_Turbinis_Calc_Book.ipynb` (яч. 5, 9, 12–16, 28), `Turbinis-Cycle/Turbinis-Cycle.ipynb` (яч. 2–5, 11), `Optimizer/optimizer_core.py` (границы + `validate`).

## Главный вывод

Предложение в целом **верное как книжная рамка**, но:

1. Оно описывает **другую схему**: 1 ступень ТК + 1 ступень СТ, два вала, `D_вт = const`. Наш основной проект — **3-ступенчатая одновальная** турбина TPE331, `D_вт` по ступеням разный (47 / 75 / 71 мм). Поэтому пп. 3–4 предложения к основному коду напрямую не применимы.
2. В самом предложении есть **неточности по страницам** (ниже).
3. Наш код совпадает с книгой **частично**: главные пробелы — рис. 18, запас `n < n_max`, нижняя граница `l/D`, `D_вт = const`, и расхождение проверок блокнота и оптимизатора.

## 3. Что варьируется: предложение ↔ оптимизатор

| Предложение (группа 1) | Наш оптимизатор |
|---|---|
| `n` | **не варьируется** — получается из σ и `A_т` |
| `l/D` | варьируется (`lD`) ✅ |
| `ρ` | **не варьируется** — получается из `l/D` по табл. с. 58 |
| `c2a` | **не варьируется** — получается через `κ` |
| — | фактически варьируются: `D1, D2, lD, α1(1..3), веса π, κ(1..3), σ_л` |

То есть предложенная группа независимых переменных **не совпадает** с текущей параметризацией. Это не ошибка кода, но если делать «новый оптимизатор» по предложению, его надо переписать на `n, l/D, ρ, c2a`.

## 5. Главные расхождения в коде (по важности)

1. **Рис. 18 не реализован.** `ρ` берётся из таблицы с. 58, `u` — из `D` и `n`; связи `(u/c0)опт(ρ)` и `(u/c1)опт(ρ)` нет. Это ровно то, с чего предложение предлагает начинать.
2. **`l/D` в оптимизаторе 0.20…1/3**, проверка только сверху. Книга: 1/4…1/3,5 (до 1/3). Нижняя граница 0.20 — не книжная.
3. **`σ_л` 250…400**: 400 > книжных 300. Строгий лучший вариант (`l = 10.43`) вообще сидит на σ = 395 МПа — **вне книги**. Плюс цикл считает `n_max` при 160 МПа, а расчёт — при 290 МПа; это разные `n_max`.
4. **`n = n_max`** без запаса; книга говорит `n < n_max`.
5. **`κ < 1` разрешён** (0.95…1.40), хотя комментарий модели требует `κ > 1`. Либо проверять, либо убрать комментарий.
6. **`D_вт = const` не реализован**; `Dнар` не считается, `D_вт > 0` явно не проверяется. Для схемы из предложения нужен отдельный режим.
7. **`optimizer.validate` — не полная проверка блокнота.** В нём нет `φ/ψ ≤ уточнённых`, `l/b_a`, `b_a_min`; зато есть жёсткие `α1 ≥ 11`, `σ` без 0.5 %, длины без 0.999. А блокнот (яч. 28) наоборот: `α2 +1°`, `σ·1.005`, длины `·0.999`, `α1` и `u > 400` — только «замечания». **Два разных источника истины.**
8. **Базовая точка `α1₁ = 9.25°`** нарушает ваше же `α1 ≥ 11°`. Блокнот это только отмечает, оптимизатор — валит.
9. **`δ/l = 0.005`** ниже книжных 0.007…0.01; оправдано только сотами (0.2 мм, с. 12).

## 6. Что в коде уже правильно

- `α2` 70…90 / 80…90 — точно по с. 38, по умолчанию строго.
- Таблица `l/D ↔ ρ` (1/9→0.2, 1/6→0.3, 1/4→0.4, 1/3→0.5) — точно по с. 58.
- `n_max` через `σ = k_n n² A`, `k_n = 6.8e-6` — по с. 56–57.
- `σ_р ≤ σ_л`, `p2z = p_т`, `N`, неразрывность, энергия — есть.
- `M < 1` не навязывается; проверяется `λ_c1 ≤ 1.05` (с. 78).
- `c2²/2`, `η_u`, `η_л`, `η_т*`, `ξ_з`, `ξ_тв`, `ξ_в` — считаются.
- `γ ≤ 25°` — по с. 56.
- `π_ст 1.8…2.4` и `l_с1 ≥ 14/20` **честно помечены как проектные**, не книжные. Это правильно.

## 7. Что предлагаю поправить

1. `lD` → 0.25…1/3 и проверять обе границы.
2. `σ` → не выше 300 (или явное обоснование материала); согласовать 160 и 290 между циклом и расчётом.
3. Добавить запас `n ≤ q_n·n_max` (например, 0.95) или резерв по σ.
4. Оцифровать рис. 18 и добавить проверку `u/c0`, `u/c1` (или хотя бы вывод фактических значений против кривых).
5. Добавить `D_вт > 0`, `Dнар > Dср`; при необходимости — отдельный режим `D_вт = const`.
6. Ввести проверку `κ > 1` (или убрать требование из комментария).
7. Свести проверки блокнота и `validate` к одному набору: `φ/ψ`, `l/b_a`, `b_a_min` — в `validate`; убрать `+1°`, `·1.005`, `·0.999` из блокнота.
8. `δ/l` — либо 0.007…0.01, либо явная ссылка на соты (0.2 мм) как принятое решение.
