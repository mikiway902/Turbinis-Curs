## 2. Матрица расчётов

| модель | замыкание | назначение |
|---|---|---|
| M0 | `ds/dr = 0` | изоэнтропический контроль (книга) |
| M1 | `h_с ∝ c1²`, `s = s₀ + h_с/T` | локальные потери по полному напору |
| M2 | `h_с ∝ c1a²` | потери по осевому напору |
| M3 | распределение потерь по профилю | основная физическая модель **при наличии данных**; сейчас данных нет |
| M4 | нижняя/верхняя границы потерь | полоса неопределённости |

Для каждой модели: `ρ_корня`, `ρ(r)`, `α1(r)`, `p(r)`, `T(r)`, расход,
работа, выходные треугольники, КПД.

## 3. Термодинамическая проверка M1

До использования M1 как основной:

1. Проверить, что `h_с` — необратимая потеря вдоль линии тока, а не разность
   идеальной и фактической кинетической энергии в сечении.
2. Температура диссипации: `s = h/T` корректно только при `T` на линии тока;
   проверить чувствительность к `T` (статика сечения vs средняя по процессу).
3. Проверить, что при `φ → 1` модели M0 и M1 совпадают.
4. Проверить знак и величину `ds/dr` по высоте; при `φ=const` и `c1(r)`,
   убывающей к периферии, `s` должна расти к втулке.

## 4. Выход РК: `p2(r)`, `T2(r)`

Сейчас модель их не задаёт; проверка выхода неполная. Требуется:

1. Распределение работы `L_u(r) = c1u(r)u1(r) + c2u(r)u2(r)`.
2. Энергия: `T2(r)` из `L_u(r)` и `w2(r)`.
3. Энтропия за РК: потери `ξ_л` по радиусу (M1/M2).
4. Радиальное равновесие за РК: `dp2/dr = ρ2(c2u²/r − T2 ds2/dr)`.
5. Замыкание расхода по выходному сечению `∫ρ2 c2a 2πr dr = G_л`.
6. Проверить `w2 > c2a`, `β2`, `α2(r)`.

## 5. Анализ чувствительности

На контрольной точке и на 3 точках категории E:

- полоса `ρ_корня` по M0…M2;
- полоса `α1(r)`, `α2(r)`, `p(r)`, `T(r)`;
- влияние граничного условия `p(r_ср) = p1` (альтернатива — `p(r_вт)` из (71));
- влияние `φ`, `ψ` в пределах 0.95…0.98.

Критерий: если полоса `ρ_корня` не пересекает 0.05 — решение устойчиво;
если пересекает — фиксировать как «зависит от модели потерь» и не выдавать
за допустимое.

## 6. Критерии приёмки

1. M0 воспроизводит книгу (расхождение ≤ 0.3 % по `p(r)`).
2. M1/M2 проходят проверки п. 3 (монотонность `s(r)`, `φ→1`, знак).
3. Замкнут выход РК: расход, работа, равновесие, `w2 > c2a`.
4. Получена полоса `ρ_корня` по всем моделям.
5. Контрольная точка 6Б пересчитана во всех моделях; результат сравнён
   с `book_approx`.

## 7. Что не делать

- Не выбирать замыкание по тому, проходит ли ρ ≥ 0.05.
- Не выдавать `s = h/T` за методику книги.
- Не запускать 6Б-5 до п. 6.
- Не менять ограничения.
