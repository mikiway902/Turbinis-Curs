## 2. 6Б-2. Вывод обоих законов

Обозначения: `r` — радиус, `c_u` — окружная составляющая скорости,
`c_a` — осевая, `u = ωr`, `H0` — располагаемый перепад ступени, `ρ` — степень
реактивности.

### 2.1. Γ = const (свободный вихрь)

Условие: `Γ = 2π·r·c_u = const` ⇒ `c_u·r = const`.

Радиальное равновесие на станции без работы:
`(1/ρ_г)·dp/dr = c_u²/r`.
Энергия: `h0 = h + (c_u² + c_a²)/2 = const` по `r`.
Изоэнтропа: `dh = dp/ρ_г`.

Дифференцируя `h0 = const` и подставляя равновесие:

```
dh/dr = c_u²/r
dh/dr + c_u·dc_u/dr + c_a·dc_a/dr = 0
c_u·dc_u/dr = −c_u²/r   (так как c_u = K/r)
⇒ c_a·dc_a/dr = 0 ⇒ c_a = const
```

То есть Γ = const + радиальное равновесие ⇒ **`c_a = const`, `c_u·r = const`**.

Степень реактивности (ступень с `c1 ≈ c3`, `c_a = const`):

```
ρ(r) = 1 − (c1u + c2u)/(2u)
c1u·r = K1, c2u·r = K2, u = ωr
⇒ ρ(r) = 1 − (K1+K2)/(2ω·r²)
⇒ ρ(r) = 1 − (1−ρ_ср)·(r_ср/r)²          (показатель 2)
```

### 2.2. α1 = const

Условие: угол α1 одинаков по радиусу. Совместно с закруткой это даёт
(с. 76): `c1u·r^{cos²α1} = const`, `c1a·r^{cos²α1} = const`.
Подстановка в `ρ(r) = 1 − (c1u+c2u)/(2u)` даёт

```
ρ(r) = 1 − (1−ρ_ср)·(r_ср/r)^{2cos²α1}
```

— ровно та формула, что стоит в оптимизаторе.

### 2.3. Разница

При α1 → 0 показатели совпадают; при α1 = 12…20° (первая ступень)
`2cos²α1 ≈ 1.91…1.86` вместо 2 — разница небольшая, но для ρ_корня она
складывается с изменением `p1(r)` по (71). Численно на сетке этапа 5:

| точка | ρ_корня1 по α1=const | ρ_корня1 по Γ=const |
|---|---|---|
| max α2₁ = 77.6° (n=90 тыс., D=62 мм) | 0.0423 | **0.0561** |
| все 35 точек с α2₁ ∈ 70…90 | 0.0450…0.0452, **0 из 35 ≥ 0.05** | 0.0587…0.0588, **35 из 35 ≥ 0.05** |

**Гипотеза 6Б:** переход 1-й ступени на Γ = const снимает связку
α2₁ ↔ ρ₁. Это надо проверить полным радиальным расчётом, а не подменой
одной формулы.

## 3. 6Б-3. Реализация

1. Ввести выбор закона по ступеням в оптимизаторе: `закон_ст` (по умолчанию
   `["α1", "α1", "Γ"]`, вариант — `["Γ", "α1", "Γ"]`).
2. Для выбранного закона считать ρ_корня по (71)+(73) на радиусе втулки,
   а не по упрощённой формуле.
3. Для Γ = const: `c1u(r) = c1u·r_c/r`, `c1a = const`;
   для α1 = const: `c1u(r) = c1u·(r_c/r)^{cos²α1}`, `c1a(r) = c1a·(r_c/r)^{cos²α1}`.
4. Проверять на втулке: `α1_корня ≥ 11°` (с. 73), `ρ_корня ≥ 0.05`,
   `w2 > c2a`, `c1a > 0`, `λ_c1 ≤ 1.05` на среднем радиусе (с. 78).
5. Сохранить `D_вт = const`; меридиональный контур не менять без отдельного
   решения.

## 4. 6Б-4. Проверка

- **Контроль:** старая модель (α1 = const для ст. 1–2) должна воспроизвести
  свои числа на тех же 308 точках бит-в-бит. Новая — отдельный набор.
- **Энергия:** `L_u = cp·(T*0 − T*2)` на каждом радиусе, допуск 1e-6.
- **Неразрывность:** `∫ ρ_г·c_a·2πr dr = G` по сечениям, допуск 1e-6.
- **Давление:** `p2` последней ступени = `p_т`, допуск 1e-6.
- **Размерности:** r в м, c в м/с, ρ_г в кг/м³, p в Па.
- **Согласованность:** ρ_корня по новой формуле должна совпадать с
  `профиль(s, "Γ")` из блокнота на той же точке (эталон).
- **Регресс:** 20 случайных точек — старый путь не изменился.

## 7. Риски

- Γ = const меняет не только ρ_корня, но и `α1` у корня, `λ_c1`, `w2` —
  точка может выйти за `α1_корня ≥ 11°`.
- Формулы (71)/(73) взяты из книги; их нужно сверить с оцифровкой страниц
  (с. 76, 78) до запуска.
- Книга профилирует ст. 1–2 при α1 = const; переход на Γ — **изменение
  проектного решения**, его надо фиксировать в отчёте, а не выдавать за
  исправление ошибки.
- Упрощённая формула остаётся справочной; смешивать результаты двух законов
  в одной таблице нельзя.

## 8. Чего не делать

- Не заменять формулу ρ_корня, не пересчитав радиальные профили.
- Не объявлять 18–20 мм недостижимыми до проверки Γ-закона.
- Не ослаблять α2 70…90 и ρ ≥ 0.05 ради длины.
