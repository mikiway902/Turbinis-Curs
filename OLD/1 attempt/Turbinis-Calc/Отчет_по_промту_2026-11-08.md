## 3a. Новый путь: диаметры из A и l/D

Добавлены `Turbinis-Calc/sizing.py` и `optimizer_core.evaluate_sizing`:
`A = Gv/ca` → `D_ср = √(A/(πλ))` → `l = λD_ср` → `D_вт = D_ср − l` → `D_нар = D_ср + l`.
`D_вт = const` обеспечивается подбором λ_i: для заданной `A₂` и общей цели `D_вт`
решается `D_ср = (D_вт + √(D_вт² + 4A₂/π))/2`, `λ = (D_ср − D_вт)/D_ср`.

Первая итерация (цель `D_вт = 62.4 мм`, получена как среднее текущих значений):

| Ступень | l/D | D_ср, мм | l_л, мм | D_вт, мм | u/c0 | u/c0 рис. 18 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 0.1694 | 75.2 | 12.7 | 62.48 | 0.430 | 0.559 |
| 2 | 0.2715 | 85.8 | 23.3 | 62.43 | 0.534 | 0.580 |
| 3 | 0.2898 | 88.0 | 25.5 | 62.47 | 0.565 | 0.584 |

`D_вт` совпал с точностью 0.054 мм; `l_с1 = 13.93 мм`, `α2 = 37.7 / 53.0 / 74.9°`,
`η*т = 0.9117`. Условие `u/c0 ≈ (u/c0)опт` **не выполнено** (отклонения −23 / −8 / −3 %):
это цель следующей итерации — варьировать `n`, λ_i, α1 и веса `H0`.

Пока новый путь реализован отдельно (`sizing.py`, ячейка в блокноте,
`evaluate_sizing` в оптимизаторе); старый расчёт по `D_ст` оставлен для сравнения.
Полная замена `турбина`/`решить` требует переписать внешний цикл `N/G/A_т` —
это следующий шаг.

## 3b. Замыкание D_вт = const на всех сечениях

В блокнот добавлен `ступень_const_hub`: для каждого сечения
`l = (√(D_вт² + 4A/π) − D_вт)/2`, `D = D_вт + l`; поэтому `D_вт` одинаков
перед СА, за СА и за РК. Скан `D_вт = 48…70 мм` подтвердил:
`D_вт СА = D_вт РК` с точностью до 0.01 мм, `N = 105…113 кВт`,
`α2` растёт с `D_вт`, `u/c0` приближается к рис. 18.

Лучшая аэродинамическая точка (n = 84 000, D_вт = 65 мм, веса π = [0.75, 0.80, 1.0],
G подобрано под N = 110 кВт):

| Параметр | Значение |
|---|---|
| α2 | **73.0 / 74.6 / 81.2°** — все в книжных диапазонах |
| u/c0 | 0.506 / 0.581 / 0.582 |
| u/c0 опт | 0.531 / 0.569 / 0.576 |
| l/D | 0.150 / 0.246 / 0.266 |
| N | **110.0 кВт** |
| l_с1 | **13.28 мм** (< 14) |
| σ_max | **314 МПа** (> 300) |

Сетка `n × D_вт` при `w = [0.75, 0.80]` показывает конфликт:

* `D_вт = 58 мм`, `n = 82 000` → `l_с1 = 14.66 мм`, но `α2 = 48.3 / 48.6 / 63.0°`
  и `σ = 319 МПа`;
* `D_вт = 64 мм`, `n = 84 000` → `α2 = 69.4 / 71.0 / 79.0°`, `l_с1 = 13.44 мм`,
  `σ = 316 МПа`;
* `D_вт = 65 мм`, `n = 84 000` → `α2 = 73.0 / 74.6 / 81.2°`, `l_с1 = 13.28 мм`,
  `σ = 314 МПа`.

Ни одна точка не даёт одновременно `α2` в книге, `l_с1 ≥ 14 мм` и `σ ≤ 300 МПа`.
Ближе всего: `l_с1 = 14.66 мм` при `D_вт = 58` (но α2 ниже книги и σ = 319)
или `α2 = 73/75/81°` при `D_вт = 65` (но `l_с1 = 13.28` и σ = 314).
Это уже не ошибка расчёта, а **конфликт ограничений** при выбранных `α1`, `κ`
и распределении теплоперепада. Дальше нужно либо менять `α1/κ/веса` шире,
либо принять материал с `σ_доп ≈ 320 МПа` (вне книги ≤300).

**Следующий шаг:** `ТЗ_расширенная_оптимизация_2026-11-08.md` — расширенная
оптимизация `n`, `D_вт`, `w1,w2`, `α1`, `κ`; два прогона (strict α2 и α2₁=20…90);
доказательство/опровержение существования допустимой области; без ослабления
`σ ≤ 300` и `l_с1 ≥ 14`.

## 4. Несогласованности, которые нужно решить

1. **`π*к`**: промт задаёт 6, актуальный `Turbinis-Cycle.ipynb` — 11; `π*к = 6`
   относится к двухвальной схеме `TVD_pi6`. Оставлено 11; если нужно 6 — это
   смена схемы и повторный расчёт.
2. **`σ_л`**: 290 МПа — категория «особо напряжённые» (≤300). Нужны материал,
   температура и ресурс; 120…200 — обычные, 30…100 — высокотемпературные.
3. **`l_т/D_т`**: с. 58 даёт таблицу 1/9…1/3 и рекомендацию последней ступени
   1/4…1/3,5 (до 1/3); с. 87 п. 45 — 1/3,5…1/3. По вашему указанию поиск
   расширен до **1/9…1/3**; книжная рекомендация 0.25…1/3 остаётся отдельной
   проверкой (`recommendation`), а не границей поиска.
4. **`D_вт` не задаётся.** В основной модели он вычисляется: `D_вт = D_ср − l`
   (по сечениям СА/РК отличается). 47/75/71 мм — прежние выходные ориентиры;
   при `q_n = 0.995` получены 44.6 / 75.3 / 72.9 мм (СА). `D_вт = 64 мм` — только
   отдельный экспериментальный режим `Втулка_const`, не основная модель.
5. **`q_n = 0.995`** — минимальный положительный запас; при 0.99 ломается
   порядок длин, при 0.995 — проходит. Если нужен больший запас, требуется
   перепроектирование α2/диаметров.
6. **`l/b_a`, `b_a_min`** теперь проверяются при `full=True` по геометрии венцов
   (яч. 22); в DE (`full=False`) они помечаются `NOT_CHECKED`.
7. **Рис. 18 для 1-й ступени**: `u/c0 = 0.358` против оптимума 0.602 (WARNING)
   — следствие ослабления α2 1-й ступени ради длинной лопатки. Это не ошибка
   счёта, а конфликт требований.
