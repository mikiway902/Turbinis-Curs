
## 6. Целевая функция и стратегия поиска

### Фаза 1. Допустимость

Минимизировать **нормированное максимальное нарушение**:

```
F1 = max_i ( violation_i / limit_i )
```

где `violation_i = max(0, lower − value, value − upper)` для всех жёстких
ограничений. Цель — `F1 = 0`.

Если `F1 > 0` после многократных запусков — переходить к фазе 3 (доказательство
или оценка отсутствия области), а не ослаблять ограничения.

### Фаза 2. Улучшение внутри допустимой области

Только при `F1 = 0`:

```
F2 = −l_с1  (максимизировать длину)
```

при ограничениях `η*т ≥ 0.90`, `σ` с запасом, `u/c0` ≤ 5 %.
Дополнительно построить Pareto: `l_с1` ↔ `σ_max` ↔ `η*т` ↔ `u/c0`.

### Фаза 3. Если допустимой области нет

1. Зафиксировать прямоугольник переменных.
2. Выполнить **детерминированное** покрытие: плотная сетка / branch-and-bound /
   интервальные оценки по каждому ограничению.
3. Показать, какое ограничение (или пара) делает систему несовместной:
   - `l_с1 ≥ 14` ↔ `σ ≤ 300`;
   - `α2` ↔ `D_вт`;
   - `u/c0` ↔ `n`;
   - `N = 110` ↔ `G`.
4. Построить кривые чувствительности: как меняется минимальное нарушение при
   изменении `D_вт`, `n`, `w1`, `w2`, `α1`, `κ`.
5. Сформулировать: «в прямоугольнике … допустимой области не найдено; для
   доказательства отсутствия требуется …» либо «доказано: минимальное нарушение
   ≥ …». Не смешивать эти два утверждения.

## 8. Проверка корректности промежуточных уравнений

Для каждого кандидата дополнительно проверить:

1. `A = Gv/c_a` и `A = πD_ср l` дают одну и ту же площадь (≤ 1e-6).
2. `D_ср = D_вт + l`, `D_нар = D_вт + 2l`, `D_вт = D_ср − l`.
3. `u = πD_ср n/60`; `u/c0` и `u/c1` определены по тем же `u` и `c0/c1`, что в
   треугольниках.
4. `α2` считается по `atan2(c2a, c2u)` и сравнивается с книжным определением
   (с. 38, 90); `β2`, `c2u`, `w2` — из тех же треугольников.
5. `ρ` — по `l/D` таблицы с. 58; `ρ_корня` — по профилированию, не подменять
   средним `ρ`.
6. `σ_р = k_n n² A_лa`; `n_max = √(σ_л/(k_n A_лa))`; `q_n = n/n_max`.
7. `p2z` последней ступени равен `p_т` цикла.
8. `N` — из суммы `G_i L_т,i`, а не подставлена вручную.
