# Engineering method authority

These documents separate physical method from implementation. Equation status
means:

- **ACCEPTED** — approved physical relation; changing it requires explicit
  user approval.
- **EXPERIMENTAL** — under investigation; it must not be used as validated
  design evidence.
- **REJECTED** — retained to prevent accidental reintroduction.
- **NOT_CHECKED** — required evidence is absent.

The implementation location and deterministic check for each equation belong
in `EQUATIONS.md`. A green software test does not promote an equation.
