## Authority vs DRAFT

`engineering/CONSTRAINTS.md` and `engineering/EQUATIONS.md` are the authority
for limits and equation status. `engineering/README.md` defines the status
values `ACCEPTED`, `EXPERIMENTAL`, `REJECTED`, and `NOT_CHECKED`.

`engineering/CONSTRAINTS_COMPARISON.md` is a `DRAFT` proposal. It records
disagreements between sources and suggests consolidation; it implements
nothing and overrides nothing. Do not cite it as a limit.

`comparisons/` and `history/` documents are analysis snapshots. Their numbers
describe the code and sources at their date and are not current limits.
