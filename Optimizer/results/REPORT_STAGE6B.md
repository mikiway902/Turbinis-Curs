# Этап 6Б: радиальное распределение реактивности — контрольный расчёт

## 1. Что проверялось

35 точек этапа 5 с α2₁ ∈ 70…90 (строгий диапазон книги, с. 38) пересчитаны
с полным радиальным профилем по трём сечениям (корень / средний / периферия)
для двух законов:

- **Γ = const** — `c1u·r = const`, `c1a = const`, `p1` по (71);
- **α1 = const** — `c1u·r^{cos²α1} = const`, `p1` по `c1(r)`;
- `ρ(r) = cp·T1ад/H0·(1 − (p2/p1)^{(k−1)/k})` (73).

Проверки: ρ_корня ≥ 0.05, α1_корня ≥ 11° (с. 73), λ_c1 ≤ 1.05 на среднем
радиусе (с. 78), `w2 > c2a` во всех сечениях.

## 2. Результат первого прохода

| закон | ρ_корня | α1_корня | λ_c1 | w2 > c2a | всё |
|---|---|---|---|---|---|
| α1 = const | 0.0423…0.0452, **0/35** | 12.5°, 35/35 | 0.805…0.831, 35/35 | 35/35 | 0/35 |
| Γ = const | 0.0561…0.0588, **35/35** | **10.5…10.6°, 0/35** | 0.805…0.831, 35/35 | 35/35 | **0/35** |

**Главное:** предварительный вывод «Γ снимает конфликт» верен только для ρ.
При том же угле на входе Γ даёт `α1_корня = 10.5°`, а книга требует ≥ 11°.
То есть в исходной постановке Γ-закон **не проходит** проверку корневого угла.

## 3. Подъём α1 (как в `ступень_авто`)

Чтобы выполнить α1_корня ≥ 11.15°, средний угол α1₁ поднят с 12.5° до
**13.1…13.2°** (подбор, 0.05° шаг). После этого:

- ρ_корня1 ≥ 0.05 — **19/35** (подъём угла частично съедает выигрыш Γ);
- α1_корня = 11.15…11.25 — 35/35;
- λ_c1, w2 — 35/35;
- **все три α2 — 0/35**: α2_1 = 71…74° (норма), α2_2 = 75…83° (норма),
  α2_3 = **91.8…93.5°** (нужно 80…90).

То есть подъём α1 лечит корень, но выводит α2₃ за верхнюю границу.

## 4. κ3 как замыкающий параметр

При фиксированной точке (n=90 тыс., D_вт=62 мм, w2=0.81, w1=0.70, κ2=1.0875)
просканирован κ3 с подбором α1₁:

| κ3 | α1₁ | α1_корня | α2₁/α2₂/α2₃ | ρ1/ρ2 | σ | q_n | η | l_рк1...3 |
|---|---|---|---|---|---|---|---|---|
| 1.20 | 13.10 | 11.17 | 70.9/83.3/**87.1** | 0.0612/0.0577 | 305 | 1.0082 | 0.9040 | 12.7/14.0/21.2 |
| 1.25 | 13.15 | 11.20 | 71.0/83.3/**89.5** | 0.0611/0.0576 | 295 | 0.9921 | 0.9036 | 12.8/14.2/20.6 |
| 1.30 | 13.15 | 11.17 | 71.0/83.3/**91.8** | 0.0608/0.0575 | 287 | 0.9778 | 0.9032 | 13.0/14.4/20.2 |

κ3 = 1.25 — оптимум: все α2 в норме, ρ, σ, q_n, η проходят.

## 5. Сколько таких точек

Те же 35 точек при κ3 = 1.25 и подборе α1₁:

| κ3 | α2 ок | ρ ок | σ/q ок | η ок | **всё (углы+ρ+σ+η+рост)** |
|---|---|---|---|---|---|
| 1.20 | 19/35 | 19/35 | **0/35** | 27/35 | 0/35 |
| 1.25 | 4/35 | 19/35 | 3/35 | 25/35 | **3/35** |

Три полностью допустимые точки (кроме новой цели по длине):

```
n=90 тыс., D_вт=62 мм, w2=0.88, w1=0.70, κ2=1.0875, κ3=1.25, α1_1=13.1
α2 = 71.1/81.2/89.6°, ρ = 0.0609/0.0673, σ = 295 МПа, q_n = 0.9910,
η_t* = 0.9043, l_рк = 12.78 / 14.70 / 20.61 мм (рост выполняется)
```

## 6. Что это значит

1. **Конфликт α2₁ ↔ ρ₁ снят** переходом 1-й ступени на Γ = const — но не сам
   по себе, а в связке «Γ + подъём α1 до 11° + κ3 = 1.25».
2. Впервые есть точки, где одновременно выполнены все углы (70/70/80),
   обе корневые реактивности, α1_корня ≥ 11°, σ ≤ 300, q_n ≤ 0.995 и η ≥ 0.90.
3. **Оставшийся барьер — длина**: у этих точек `l_рк1 = 12.78` мм, нужно 16.
   Конфликт сместился: раньше α2₁ ↔ ρ₁, теперь `l_рк1` ↔ α2/η.
4. 16 мм достигались только при ослабленных углах (α2₁ ≈ 30°); при строгих
   углах и Γ-законе максимум пока 12.78 мм.

## 7. Что дальше (6Б-5)

Сканировать n и D_вт при Γ-законе, α1₁ по α1_корня ≥ 11.15° и κ3 ≈ 1.25:
искать область, где `l_рк1` растёт к 16 без нарушения углов. Ожидание: ниже n
длина растёт, α2₂ и η падают — проверить, хватает ли Γ-закона, чтобы удержать
ρ при этих n.
