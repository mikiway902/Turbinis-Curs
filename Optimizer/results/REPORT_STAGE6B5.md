# Шаг 2: радиальное равновесие с потерями (прототип 6Б-4.5)

## Замыкание

Уравнение: `(1/ρ)dp/dr = c_u²/r − T·ds/dr`.
Методика книги не задаёт `s(r)`, поэтому принято простейшее замыкание:
потери СА локальны и пропорциональны местному скоростному напору при
постоянном по высоте φ:

```
h_c(r) = (φ⁻² − 1)·c1(r)²/2
s(r)  = s₀ + h_c(r)/T(r)
```

Граничное условие — `p(r_ср) = p1` из среднесечного расчёта ступени;
`c_u(r)` по закону профилирования, `c_a(r)` по закону (Γ: const,
α1: `c_a·r^{cos²α1} = const`), `T(r)` из энергии.

Это **одно из возможных** замыканий, не доказанное методикой.

|---|---|---|---|---|
| 1 | Γ | −1.07 % | **0.0609 → 0.0457** | −0.14 % |
| 2 | α1 | +0.01 % | 0.0673 → 0.0675 | −0.77 % |

| 1 (контроль) | α1 | +0.01 % | 0.0390 → 0.0391 | −0.82 % |

## Что это значит

1. Для α1-закона энтропийный член почти не меняет результат: давление там
   уже считается через `c1(r)/φ`, потери учтены.
2. Для Γ-закона (71) изоэнтропическая, и добавление потерь **снижает**
   корневую реактивность: 0.0609 → 0.0457 (−25 %). Это ниже нормы 0.05.
3. Третья ступень (Γ) падает 0.0565 → 0.0353.
4. **Семейство «полностью допустимых» точек этапа 6Б не устойчиво** к этому

## Вывод

Прототип подтверждает опасение: при запасах 0.4–1.8 % радиальная поправка
того же порядка, что и запас. Прежде чем сканировать 16 мм, нужно:

- обосновать замыкание `s(r)` (постоянный коэффициент потерь по высоте,
  распределение потерь по сечениям, граничные условия на втулке/периферии);
- проверить альтернативные замыкания и получить полосу неопределённости;
- решить радиальное равновесие на выходе РК (`p2(r)`, `T2(r)`) — сейчас
  модель их не задаёт, и проверка выхода неполная.

До этого результаты 6Б считаются допустимыми **только в приближении книги**
(`book_approx`), не в строгом радиальном расчёте.

# Шаг 5: физический смысл h_c, выход РК, BC

## 5.1. Что такое h_c (п. 103)

`h_c = (φ⁻² − 1)·c1²/2` — это **диссипированная кинетическая энергия**
относительно изоэнтропического расширения:

```
c1_ad = √(2H_c),  c1 = φ·c1_ad
(c1_ad² − c1²)/2 = c1²/2·(φ⁻² − 1) = h_c
```

При адиабатическом течении без работы `T ds = dh_loss`, поэтому для малых
потерь `Δs = cp·ln(1 + h_c/(cpT)) ≈ h_c/T`. Оценка ошибки приближения
на втулке ст. 1:

| величина | значение |
|---|---|
| `h_c` | 12.35 кДж/кг |
| `h_c/(cpT)` | 0.0097 |
| `s ≈ h/T` | 11.399 Дж/(кг·К) |
| точное `cp·ln(1+h/(cpT))` | 11.344 Дж/(кг·К) |
| отличие | **0.49 %** |

Для РК при `h_л/(cpT) ≈ 0.033` ошибка ~1.6 %. То есть `s = h/T` — корректное
приближение первого порядка с известной погрешностью ≤ 1.6 %, а не
произвольная формула. Но это **наш вывод**, а не текст методики.

# Шаг 6: диагностика А для α₁-ступени

Норма невязки (по всему сечению, ρ_г — плотность газа в кг/м³):

```
ε_RRE = max_r|R(r)| / max_r|(1/ρ_г)·dp/dr|,
R(r)  = (1/ρ_г)·dp/dr − c2u²/r + T·ds/dr        [м/с²]
```

По соотношению Гиббса `T ds = dh − dp/ρ_г` при термодинамически согласованных
`p, T, s` энтропийный член сокращается аналитически:

```
R = dh/dr − c2u²/r = cp·dT/dr − c2u²/r          [м/с²]
```

|---|---|

77 кПа/м. Для Γ-ступеней эта же связка согласована (0.01–0.1 %), потому что
`c2u·r = const` — равновесно-совместимый закон.

Отсюда рабочая гипотеза для Б: несовместимость не в энтропийном замыкании,
а в паре «энергия `T2(r)` + закон `c2u(r)`», вероятно, из-за того, что
сечения на входе и выходе РК сопоставляются по одинаковой доле высоты
(`r1 = r_c + f·l_c`, `r2 = r_л + f·l_л`), хотя реальные линии тока
не радиальны.

## 6.3. Нули и максимумы

- `dp/dr` меняет знак при x/l = 0.859 (α1) и 0.918 (Γ ст.1), 0.515 (Γ ст.3);
  поточечная нормировка невязки на `dp/dr` поэтому непригодна.
- Максимум `|R|` — на втулке (x/l = 0), во всех вариантах.

# Шаг 7: R_full против R_h и сопоставление по расходу

## 7.1. Термодинамическое тождество

На всех трёх ступенях посчитаны одновременно

```
R_full = (1/ρ_г)·dp/dr − c2u²/r + T·ds/dr
R_h    = cp·dT/dr − c2u²/r
```

| ступень | max|R_full − R_h|, м/с² | max|(1/ρ)dp/dr|, м/с² | относительное |
|---|---|---|---|
| 2 (α1) | 16.6 | 693 908 | 2.4·10⁻⁵ |
| 1 (Γ) | 10.0 | 625 026 | 1.6·10⁻⁵ |
| 3 (Γ) | 23.6 | 628 219 | 3.8·10⁻⁵ |

Совпадение до 4·10⁻⁵ подтверждает: (а) соотношение Гиббса выполняется,
(б) энтропийный член в остатке сокращается, как и должно, (в) реализация
`T·ds/dr` согласована с состоянием. Остаток — это именно
`cp·dT_2/dr − c2u²/r`.

## 7.2. Сопоставление линий тока по накопленному расходу

`μ(r) = ∫ρc_a2πr dr / G`, линия тока — `μ1(r1) = μ2(r2)`.

| ступень | отображение | ε_full | ε_h | α2 вт/пер |
|---|---|---|---|---|
| 2 (α1) | equal-span | 13.41 % | 13.41 % | 75.4/84.8 |
| 2 (α1) | equal-mass | 13.41 % | 13.41 % | 75.4/84.8 |
| 1 (Γ) | equal-span | 0.01 % | 0.01 % | 67.6/73.7 |

сопоставлении линий тока **не подтверждается** (но и не опровергается:
эффект слишком мал, чтобы объяснить 13 %).

## 7.3. Вывод

Невязка 13.4 % — это нарушение `cp·dT_2/dr = c2u²/r` при законе α1:
энергетическое `T_2(r)` (из относительного движения) и `c2u(r)` (из
`L_u = const`) не согласованы с радиальным равновесием. Для Γ-ступеней
`c_u·r = const` — равновесно-совместимый закон, и невязка 0.01 %.

Это локализует задачу Б: искать совместное решение именно для пары
«`T_2(r)` + `c2u(r)`», с корректным счётом неизвестных:

| блок | уравнений |
|---|---|
| энергия | N |
| состояние | N |
| энтропия | N |
| равновесие | N−1 |
| BC по p | 1 |
| **итого** | **4N** |

Неизвестных 4N: `p2, T2, c2u, ρ2` на N узлах. Условие расхода — пятое
глобальное уравнение, поэтому нужна одна глобальная неизвестная (масштаб
`c2a`, высота канала или параметр закона закрутки). Иначе система
переопределена.
